# 平台适配矩阵（实测结论）

> 以下结论来自本项目实测（扫码登录 → Cookie 抓取 → 检索验证，2026-08）。平台策略随时变化，请以最新实测为准；如有出入欢迎提 Issue/PR 更新本表。

## 已知坑（实测踩过，务必注意）

1. **匿名关键 Cookie 误触发**：小红书未登录也下发 `web_session`、知乎未登录也下发 `z_c0`——`get_cookies.py` 的关键 Cookie 自动检测可能提前触发，抓到的是匿名会话。**要等真正登录请用 `--signal` 信号文件模式**。
2. **无交互终端**：stdin 立即 EOF 时脚本自动降级（打印提示并继续等待），不会像旧版那样误抓；配合 `--signal` 最稳。
3. **搜狗反爬**：连续高频检索会触发验证码（输出 `captcha=true`），降低频率或稍后重试。
4. **微信网页版账号限制**：部分微信号被腾讯安全策略禁止使用网页版微信（扫码后返回「暂不支持使用网页版微信」），属账号级限制，非脚本问题。
5. **搜狗链接跳转**：结果 `href` 是搜狗加密跳转链接（`weixin.sogou.com/link?url=...`），需在浏览器中打开才能到达公众号原文。
6. **小红书搜索卡片 DOM**：部分视频类卡片标题在不同节点，抓取可能缺标题字段（约 13/50），其余字段完整。
