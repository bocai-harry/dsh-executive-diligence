# 合规与免责（Compliance）

## 使用边界（必须遵守）

1. **仅限公开信息**：只检索公开渠道（新闻报道、工商公示、裁判文书、社交平台公开内容等）；不侵入、不逆向、不伪造、不绕过验证码、不攻击接口
2. **仅限合法用途**：用于背景调查、舆情管理、入职/商务尽调等合法场景；不得用于诽谤、骚扰、敲诈、歧视或其他非法用途
3. **登录态安全**：Cookie 等同登录态，仅存本机 `.env`，禁止外传或提交仓库；登录由用户本人在真实浏览器完成，脚本不接触账号密码
4. **个人信息保护**：涉及个人信息时遵守《个人信息保护法》等适用法律——最小必要、目的限定；报告与台账中避免收录无关敏感信息（如未公开的家庭住址、联系方式、身份证号等）
5. **反爬与风控**：保持低频抓取，遵守目标平台服务条款；触发验证码或风控时立即停止并降低频率，不绕过
6. **特殊对象审慎**：未成年人、涉密单位、现任公职人员等对象审慎评估，必要时不做

## 内容与分级规范

- 报告区分 **事实 / 指控 / 传闻** 三级；负面内容仅为线索，**不作结论**
- 同名他人必须明确区分（公司/职务/地域/出生年交叉验证）
- 每条结论带**信源 URL 与检索日期**；无法核实的内容明确标注
- 报告含**风险评级**（高/中/低 + 依据列表）
